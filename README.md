# Cardworx Merchant Services website

Static multi-page site plus an agent portal (portal.html, Supabase backend in supabase/). Edit `site-master.html`, then run `python3 build.py` to regenerate `index.html` and the sub pages.
Assets are fetched automatically by the GitHub Action from the two manifest files.
Live at: https://craftmaster7.github.io/cardworx/
